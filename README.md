# CrackerCart React app

Install Node.js, extract this folder, open a terminal here and run:

    npm install
    npm run dev

Open the local URL from Vite. For phone use, connect the phone and computer to the same Wi-Fi and open Vite's Network URL.

Features: full cracker catalogue, instant search, Regular/Fancy filters, quantity controls, add product photos from camera/gallery, percentage discount, live totals, sequential Save order & clear, Admin order history, print and JSON export.

Storage is local to this browser/device. No password or server. Clearing browser data/private browsing can remove records; export order records regularly for backup.
